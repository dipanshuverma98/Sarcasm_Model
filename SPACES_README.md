# 🎭 Sarcasm Detection

Fine-tuned BERT model for detecting sarcasm in social media text.

- **Model:** `bert-base-uncased` fine-tuned on 200K COVID-19 tweets
- **Accuracy:** 89.1% | **F1:** 0.891 | **ROC-AUC:** 0.950
- **GitHub:** https://github.com/dipanshuverma98/Sarcasm_Model
